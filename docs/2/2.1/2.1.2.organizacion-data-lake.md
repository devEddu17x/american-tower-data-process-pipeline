| Zona o ruta   | Contenido                                                                                                  | Función                                                         |
| ------------- | ---------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| **Bronze**    | Archivos originales, respuestas de metadatos y manifiestos de ingesta.                                     | Conservar la evidencia de origen y permitir el reprocesamiento. |
| **Silver**    | Datos normalizados por fuente, geometrías validadas, indicadores raster y agregaciones intermedias.        | Proporcionar información curada para la integración analítica.  |
| **Gold**      | Tablas integradas distrito–trimestre, características del modelo, predicciones e indicadores de prioridad. | Alimentar el análisis, las consultas y el tablero.              |
| **Artifacts** | Modelos, preprocesamiento ajustado, métricas, contratos de entrada y configuraciones.                      | Mantener versiones reproducibles del proceso predictivo.        |

Las zonas se implementarán mediante prefijos identificables en S3. Su representación mediante varios iconos no exige crear un bucket por fuente o por etapa. La separación física de buckets se utilizará cuando exista una necesidad concreta de permisos, retención o administración.

| Prefijo propuesto                   | Contenido                                                    |
| ----------------------------------- | ------------------------------------------------------------ |
| `bronze/<fuente>/snapshot_id=<id>/` | Archivos originales y metadatos de la versión incorporada.   |
| `silver/<tabla>/version=<id>/`      | Datos normalizados por fuente.                               |
| `gold/<tabla>/version=<id>/`        | Tablas integradas y aprobadas para consumo.                  |
| `quarantine/<fuente>/run_id=<id>/`  | Registros rechazados y motivos de rechazo.                   |
| `artifacts/config/`                 | Configuraciones y contratos de datos versionados.            |
| `artifacts/models/`                 | Modelos y transformaciones, cuando se desarrolle el punto 4. |
| `evidence/run_id=<id>/`             | Manifiestos, calidad, métricas y reportes de ejecución.      |
| `benchmarks/escenario=<factor>/`    | Entradas y salidas exclusivas de las pruebas de rendimiento. |
| `logs/`                             | Registros de ejecución y eventos de Spark.                   |

Las tablas de Silver y Gold utilizarán preferentemente Parquet con compresión. Las geometrías se conservarán en una representación documentada, junto con su sistema de referencia espacial. Los archivos raster podrán mantenerse como GeoTIFF; sus estadísticas y características derivadas se publicarán como tablas. No se convertirá indiscriminadamente todo el contenido original a un único formato.
